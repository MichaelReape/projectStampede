# STAMPEDE — AI-Powered Memory Palace 

A first-person virtual “memory palace” where you generate mnemonic images and 3D objects from text prompts, place them in a procedurally built environment, and save/load entire palaces.

## What you can do

- Generate a palace of any size with a Wave Function Collapse (WFC) map generator so rooms connect logically.

![ActivityDiagramWFC](https://github.com/user-attachments/assets/74e98b13-0184-429a-8f56-d34b0668d889)

- Create mnemonic devices from text:

    - Images via SDXL-Turbo.

    -  3D objects via Stable Fast 3D (SDXL image → textured GLB mesh).

- First-person navigation (WASD + mouse) for natural placement and recall.

- Save/Load entire palaces to JSON (rooms, images, object transforms).

## How it works (short)
![Architecture diagram](https://github.com/user-attachments/assets/2173c82d-8e86-45f3-bb41-f15a44ebcfe6)

- Unity client (C#): first-person UI, WFC generator, GLTFast import for GLB meshes, JSON persistence.

- Python backend (Flask): two endpoints the Unity client calls

    - POST /generateImage → returns PNG from SDXL-Turbo

    - POST /generate3D → returns GLB generated by Stable Fast 3D
(Unity sends the prompt; Flask runs the models and streams results back.)

For the full architecture and evaluation, see the thesis in this repo.

## Results (from evaluation)

- Scalability: reliably generates up to 64 rooms in testing.

- Performance (local, example machine): image ≈ 36s, 3D object ≈ 6m 30s.

- Persistence: accurate reconstruction of saved palaces in tests.
